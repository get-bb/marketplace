## Tell your agents apart

Custom agents in BB often share one generic icon. Agent Icons gives each provider its own icon and colour, so you can tell agents apart in the thread list, the agent picker and settings. It works for Codex and Claude Code too.

## Built-in glyphs or your own SVG

Choose a built-in BB glyph or upload your own SVG icons in named sets. Uploaded files are cleaned on the server: scripts, links, images and styles are removed, and icons become monochrome so they follow the colour you pick. Colours are set separately for the light and dark theme.

## Same on every device

Assignments are stored on the BB server, so your Mac and your phone show the same icons, and changes apply live. A provider that gets a custom icon for the first time needs one reload on each device. Disabling the plugin restores every original icon; providers are never changed.

## Getting started

Open the plugin's settings page, press **Change** next to a provider, pick an icon and optional colours, and save. The `bb agent-icons` command does the same from a terminal and can import a folder of SVG files as a set. Requires BB 0.49.0 or later, below 1.0. The interface is English by default; Russian is available through the `language` plugin setting.
