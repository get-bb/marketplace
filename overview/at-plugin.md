## Find the right plugin

Type `#` in the composer followed by a keyword, such as `#pdf`, to search the plugins you have and the ones in BB Community. Type `#plugins` to browse everything. The `@plugin` syntax also works.

Search covers names, plugin IDs, full descriptions, and long-form overviews. Community results also match tags and categories. Installed matches appear without waiting for the catalog.

## Point your agent at it

Select a result to add a plugin mention to your message. Mention an installed plugin to tell your agent which one to use, or mention a Community plugin to discuss whether it fits. A mention never installs, enables, or runs a plugin by itself.

## Let your agent search

Ask your agent to find a plugin for the task. It can run `bb at-plugin search "keyword" --json` and `bb at-plugin show <plugin-id> --json`, which return descriptions, overview text, and screenshot links it can show you.

## Availability

Installed results include enabled, running plugins. Community results include compatible plugins you have not installed.
