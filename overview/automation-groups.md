## Organize scheduled work

Group BB automations into named folders. Search across projects, move automations between groups, and pause, resume or run a group together. Inspect execution history, errors and agent transcripts from the detail view.

## Requirements and data

Requires the bundled Automations plugin. Scheduled agent runs use your configured provider accounts and quotas. This plugin stores group names and membership; automation definitions remain in Automations. A fresh installation creates no schedules and includes no personal automation definitions.
