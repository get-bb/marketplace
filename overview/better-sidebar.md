# Better Sidebar

A T3 Code-inspired sidebar thread list for BB.

## Features

- **Active, Working, and Settled**:
  - **Active / Attention** at the top for threads that are not settled yet.
  - **Working** for threads currently running or awaiting interaction, with a live spinner and relative timer.
  - **Settled** (collapsible) for threads you explicitly marked as finished.
- **Explicit Settle / Unsettle**: Mark any thread as settled (`✓✓`) or move it back (`↺`) directly from the row, including on mobile viewports.
- **Project Badges**: Color-coded initial avatars for quick visual scanning across projects.
- **Quick Search & Filter**: Filter threads by title, project, or host, and toggle between `active`, `archived`, and `all`.
