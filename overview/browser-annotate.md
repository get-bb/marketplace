## What you get

Add comments to elements in a native BB Browser tab and send one batch to the current chat. Each selected element keeps its page context and its own screenshot, so the agent can see which part of the page each comment refers to.

## How it works

Choose **Annotate** in the Browser toolbar, select an element, and enter a comment in the editor below the Browser toolbar. Save more selections to build a batch; the page shows numbered markers and selection highlights while the editor stays in BB's renderer. Send the batch directly from **Annotate Page**, or keep it as a Browser comments mention in the composer and send it with your next message. The sent mention remains available in thread history: hover it to review the comments and screenshots.

## Requirements

Use BB 0.43.4 or newer with its native desktop Browser. The plugin handles the top-level page document; cross-origin iframe content, arbitrary regions, and virtual targets are not selected. Screenshots cover the visible viewport and each batch supports up to 50 annotations. Install the plugin separately in BB from Git.
