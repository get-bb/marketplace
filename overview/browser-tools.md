## What you get

Agents can navigate websites, inspect accessibility snapshots, click, type, and capture screenshots through native BB tools. A capability notice and browser skill explain when and how to use them.

## Browser checks

Use snapshot references to target elements and review the page state returned after actions. Inspect console errors and failed HTTP requests while testing web apps. Screenshots arrive as image attachments; Codex in-session image rendering remains unverified.

## Control and permissions

Each session controls one browser tab for up to thirty minutes. Stop or Take over ends control and retains the tab. Enter credentials manually. Personal-tab access and consequential actions require appropriate authorization. JavaScript evaluation is disabled by default; enabling it permits trusted arbitrary JavaScript, not a read-only sandbox.

## Requirements and limits

Requires BB 0.43 or later, a connected BB desktop browser, and an agent provider. Provider costs and website account requirements still apply. No separate browser automation server is required. Tested on macOS; other host operating systems are unverified. Popups, uploads, downloads, and multi-tab sessions are not supported.
