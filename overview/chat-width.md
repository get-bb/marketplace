## Your two comfortable widths

Keep a reading column and a wider working column, then switch between them from the conversation header. Tune either preset with a slider or an exact whole-pixel value. Fill uses the available pane width.

## Fits the workspace

Messages and the primary input box stay aligned. A narrow pane temporarily limits the visible width without changing your saved maximum. On compact screens, the controls open in a bottom drawer.

Use bb default to restore BB's layout while keeping both presets. A fresh installation starts with native layout.

## On this device

Choices stay in this browser and apply to its supported conversation panes. No account, API key or external service is required. New-thread compose and message editors keep the host layout.

## Compatibility

Targets BB 0.47.1 with Plugin SDK 0.6.79. This utility uses internal conversation layout selectors, so a BB update can require a compatibility update. An unsupported layout stays native.
