## Light and dark

Keep one palette selected while BB follows Light, Dark or System appearance. Dark mode uses charcoal surfaces and beige text. Light mode uses off-white surfaces and charcoal text. Both use terracotta accents for selected navigation, active-tab underlines and tinted hover states.

## Code and terminal colours

Diffs and file previews switch to the matching syntax palette. The plugin includes SK's original dark and light syntax files and maps each variant's 16 terminal colours to BB. Fonts and layout use BB defaults. Custom plugin navigation may use different selection states.

## Getting started

After installation, open Settings → Appearance and select Claude Theme under Palette. Choose Light, Dark or System under Theme. No account, external service or VS Code installation is needed. Requires BB 0.47.1 or later, below 1.0, and Plugin SDK 0.6.79 or later, below 0.7.
