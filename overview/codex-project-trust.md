# Codex Project Trust

Approve a project trust warning from the Codex thread that reported it. The card shows the path up front and reveals the execution machine and Codex user configuration before you commit to a change.

## What you get

- A compact trust card under the thread header.
- A review step that explains how trust enables local settings, hooks, and command execution rules.
- A verified save through Codex App Server on the machine running the thread.
- English and Russian labels based on browser language.

## Requirements

BB 0.50.1 or newer and Codex CLI 0.170.0 or newer on the connected execution machine. The Codex user configuration used by the host daemon must match the one in the warning. Codex applies the setting when the thread runtime next starts.
