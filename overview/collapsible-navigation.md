Reclaim sidebar space with a collapsible navigation panel that folds upward.

## What you get

- An upward-collapsible navigation strip that frees space for your thread list.
- Quick action buttons accessible even when collapsed.
- An optional header icon bar for moving navigation directly into the top window bar.

## How to use

1. Install the plugin in BB.
2. In Settings → Appearance → Navigation, ensure **Collapsible Navigation** is active (or Automatic).
3. Click the **Navigation** header or the chevron icon in the sidebar to collapse upward or expand.
