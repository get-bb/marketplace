## Where chips appear

Color literals get a small chip inside fenced code blocks, diffs, and inline code, and beside colors written in the plain text of your submitted messages. Hex, `rgb()`, `hsl()`, `oklch()`, and other CSS color forms are recognized.

The chip shows alpha over a checkerboard and has a faint ring, so `#ffffff` and `#000000` stay visible on any theme.

## What stays the same

Code is never rewritten. Streaming, selection, and copied text behave exactly as before. The composer is never decorated.

Hex colors must use the six-digit or eight-digit form. Three- and four-digit values are left alone so issue and PR references such as `#123` are not mistaken for colors.

There is nothing to configure.
