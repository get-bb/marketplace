## Follow conversations in one place

Keep agent conversations, results, and requests for input in one panel.

Open Agent Channels from a thread’s header or right panel. Each worker, parent,
or peer that messages the thread gets its own channel, with messages and results
in order. Activity dots distinguish new messages from agents waiting for input.
Scroll up to read older history.

## Coordinate work

Six bundled skills cover delegating a bounded task, relaying decisions,
collecting results, reporting outcomes, managing finished threads, and deriving
settings from your instructions. Choose when agents may start workers and
whether they report to their lead or directly to you.

## Use your preferences

Settings provides provider, model, and reasoning choices for leads, parents,
workers, and QA. Recorded instructions take precedence over manual overrides;
each recorded value keeps its source and exact quote. Ask an agent to refresh
the defaults after your instructions change. Other workflow settings are
available through `bb delegation`.

## Requirements and data

Run agents with a provider configured in bb; its account requirements and usage
limits apply. No separate workflow skills are required. Optional skills can add
decision cards, capacity guidance, or cleanup workflows. Without them, bundled
skills use native bb commands and plain questions.

Channels read the current user’s existing bb threads and messages. Settings and
quoted instructions are stored in this bb. Defaults are shared across its
threads, so only instructions intended globally should be recorded. Nothing is
published to an external service by this plugin.
