## Two palettes

`endless` is the achromatic silver print: a warm silver ramp with no accent hue, where the brightest white is reserved for primary actions. `endless-color` keeps the same structure and adds rare accents sampled from the film's painted stair: light blue, mustard, orange, red, and olive.

Both palettes cover light and dark mode, so one choice follows your mode setting.

## The details

Corners are square, like photographic prints and registration marks. The UI uses Helvetica and code uses Courier, following the album's liner notes. Both are system fonts, so nothing is downloaded.

## Use it

Pick Endless in Settings → Appearance, or run `bb theme set plugin:endless:endless` for the silver print or `bb theme set plugin:endless:endless-color` for the accented version. `bb theme reset` returns to the default theme.
