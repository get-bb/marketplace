## Open space in one click

Add a Fast Split icon to the sidebar footer. It activates BB's native New thread action with split placement, keeping your existing work visible while you prepare another conversation.

No provider work starts until you submit a prompt. Requires a wide layout, BB splits enabled and the New thread sidebar action visible. Works with standard navigation and Sidebar Subtitles. Custom navigation providers must preserve the native Cmd/Ctrl-click behavior.

At the pane cap, close an unlocked pane first. The plugin leaves pane persistence and navigation rules to BB.
