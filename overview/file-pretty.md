## What you get

Open structured files in BB's file viewer with consistent indentation. Switch
between formatted and raw content and copy the view currently on screen.

Pretty supports JSON, JSON with comments, JSON Lines, YAML, TOML, XML, and
several XML-based extensions. Parse errors show their location alongside the
original text. Files over five million characters open in raw view first.

## How it works

The BB file viewer reads files from the selected workspace, thread storage, or
machine. Formatting runs in the browser. TOML comments are not preserved in
the formatted view; the raw view retains the original file content.

## Requirements

Install the plugin in BB 0.46 or later. Other configured file openers remain
available through Open with or the Files settings.
