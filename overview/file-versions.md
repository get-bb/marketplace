Which one is it: Deck_v5, Deck_final, or Deck_final_2? File Versions finds every version of your decks, documents and spreadsheets across projects and shows the latest, for you and for your agents.

## What you get

- One page listing each document with its latest copy and older ones underneath.
- Understands v2, final, dates, and (1), in English and Russian.
- A `bb file-versions` command, so agents work from the right file.

## How it works

It reads your project folders on the BB server, plus any folders you add. It never changes a file, and nothing leaves the machine. The latest is a guess from names and dates. Other enrolled machines are not covered.
