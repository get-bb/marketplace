## Light and dark

Flexoki is an inky color scheme for prose and code by Steph Ango, inspired by analog printing inks and warm shades of paper. This plugin brings it to BB as one palette that follows Light, Dark or System appearance. Light mode uses paper surfaces and black ink. Dark mode uses near-black surfaces and warm grey text. Accents follow the Flexoki rule: the 600 range in light mode and the 400 range in dark mode, with cyan for primary actions.

## Code, terminal and text

Diffs and file previews use the official Flexoki syntax themes from the Visual Studio Code port, copied unchanged. The 16 terminal colours map to the Flexoki ANSI values. Interface text uses the system font stack from stephango.com/flexoki at Regular weight, with a compact reading scale for chat, the composer and the sidebar. Touch phones get slightly larger text.

## Getting started

After installation, open Settings → Appearance and select Flexoki under Palette. Choose Light, Dark or System under Theme. No account or external service is needed. Requires BB 0.47.1 or later, below 1.0, and Plugin SDK 0.6.79 or later, below 0.7.
