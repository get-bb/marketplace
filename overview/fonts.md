## What you get

Choose separate font families for BB's interface, code, and serif text without changing the active color theme. Tune size, weight, style, line height, and letter spacing for each role, with live specimens before you save.

## Font choices

Search fonts installed on the device viewing BB, choose a portable generic CSS family, or type a family name directly. Every property can inherit its current theme value, and reset controls restore that inheritance without changing the selected palette.

## Remote browsers

Fonts works through BB Connect and other secure browser origins. Desktop Chromium browsers can list local fonts after explicit permission; unsupported browsers and mobile clients retain generic and manual choices. Settings and scanned font metadata stay separate in each browser profile and origin because different devices may have different fonts.

## Privacy and requirements

The plugin sends no telemetry and uses no external service. Installed-font metadata remains in client-local storage and is cleared when browser permission is revoked. Full installed-font discovery requires a secure desktop Chromium context; generic and manual families do not.
