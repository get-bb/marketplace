## Two palettes, one typeface

Graphite Mono sets the whole BB interface in JetBrains Mono at Light weight. It comes in two palettes that each follow Light, Dark or System appearance. Graphite Mono uses neutral graphite surfaces, near-black or near-white text and a violet accent. Graphite Mono Matrix uses near-black green surfaces, mint text and a phosphor-green accent in dark mode, with pale green paper and deep green ink in light mode.

## Text and composer

All text, inline code and code blocks use the Light weight; bold and chat headings use 600. Chat reads at 14/24 with 13px code, and the composer's context strip and model picker use 12px. Touch phones get 15/24 text and a 16px composer, so iOS does not zoom on focus. The composer draws the project, machine and permission controls as a strip tucked behind a rounded prompt slab, with a round send button. Text selection, menus, switches and the timeline accent follow the palette.

## Getting started

After installation, open Settings → Appearance and choose Graphite Mono or Graphite Mono Matrix under Palette. Choose Light, Dark or System under Theme. The font is embedded in the theme, so no account, network request or external service is needed. Requires BB 0.47.1 or later, below 1.0, and Plugin SDK 0.6.79 or later, below 0.7.
