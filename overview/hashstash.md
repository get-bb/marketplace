## Your prompt library

Keep review instructions, writing templates, and other repeated prompts in one folder. Open HashStash in the sidebar to create, edit, or delete them. The library works across projects on the same BB server.

## Use prompts in chat

Type `#` to open the menu in any chat. Search by name, then choose a prompt with the mouse, Enter, or Tab. HashStash inserts the text into your message field immediately. Edit the text before sending.

Spaces, punctuation, Escape, or leaving the message field close the menu. Template fields such as `{{file}}` stay as text. Replace them yourself after insertion.

## Keep your files

Each prompt is a Markdown file. Its filename supplies the name, and its contents supply the prompt text. Choose your folder in the plugin configuration. Copy that folder to back up your library or move it to another computer.

You can edit the files with another editor. HashStash refreshes the library after file changes. It detects existing changes before a save or delete.

## Requirements

HashStash requires BB 0.44 or later. It needs no external service or API key. It reads and writes your selected folder with the permissions of the BB server.
