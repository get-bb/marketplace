## How it works

Open an image attached to a draft and choose **Annotate** beneath the preview.
Click a point or drag a rectangle, then write your comment. Numbered markers
link each comment to the spot it describes.

Choose **Done** to return to the draft. An icon on the thumbnail marks the
annotated image. Open it again to edit or delete its comments. Removing the
image or deleting its last comment clears the attached notes.

## Keyboard controls

Focus the image and use the arrow keys to move the crosshair. Press **Enter**
to pin a comment, or **Shift+Enter** to start a rectangle. Move diagonally and
press **Enter** to finish the rectangle.

## Requirements and storage

Uses BB's built-in composer and project attachment storage. Tested on BB 0.50.1
with Plugin SDK 0.6.157. The plugin makes no external service requests. BB sends
the comments and their coordinates as a Markdown attachment with the image
when you send the draft.
