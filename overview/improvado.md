Connect your BB agents to Improvado MCP and ask questions about the marketing data in your Improvado workspace.

## What you get

- A skill that shows agents how to connect the hosted Improvado MCP server in Claude Code and Codex threads.
- Example questions and links to step-by-step analysis recipes: cross-channel ROAS, weekly reports, spend anomalies, Google Ads, Meta Ads and GA4.

## How it works

Improvado hosts the MCP server. You sign in with your Improvado account through OAuth, and the agent sees only the sources and data your workspace permissions allow. The plugin itself stores nothing and needs no API key.
