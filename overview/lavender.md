## A softer workspace

Lavender brings soft violet colors to BB's conversations and code. Dark mode combines a near-black sidebar, charcoal-purple panels and lilac accents. Light mode pairs pale lavender surfaces with readable dark text and deeper violet accents.

Select Lavender in Settings → Appearance. It follows your Light, Dark or System mode and includes matching syntax colors for code and diffs.

Native color tokens preserve your layout, fonts and wallpaper. All assets ship locally, with no network requests or user data storage.
