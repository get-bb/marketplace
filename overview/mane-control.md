## What you get

A horse button sits beside the thread composer so you can switch Ponytail without typing a slash command. Open the menu, pick Off, Lite, Full, or Ultra, and the matching `/ponytail` command goes into the thread straight away. The button keeps the active mode in view.

Mode-command messages in the transcript render as compact `Ponytail · Mode` status pills, with the real command still available underneath.

## Requirements

[Ponytail](https://github.com/DietrichGebert/ponytail) must be installed and available for the thread's provider. Mane Control accepts the Ponytail plugin skill, a user skill, or a registry install such as skills.sh. When Ponytail is missing, the control stays disabled and mode changes are blocked.
