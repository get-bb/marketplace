# Model & Effort Badges

See each BB thread’s model family and reasoning effort without opening its composer. A model letter and small effort strokes appear at the provider logo. Hover for the full model name and effort before sending the next turn.

*Synthetic example data in BB 0.47.1 with separate [True Colors](https://github.com/ChrBoebel/bb-plugin-provider-brand-marks) 0.1.3 by ChrBoebel. Without it, badges are gray. The tooltip preserves the full model name and exact effort.*

Compare several threads at a glance. Choose a tile, a caption under the logo, or a chip beside it; tile is the default for Codex and Claude Code. Use the caption to preserve long titles. Badges show the next turn’s settings; a switch sent to an already running thread appears when it goes idle.

Default badges have no box or fill: one bottom stroke means high effort, two extra high, three max, and four ultra/ultracode. Lower efforts have no strokes. Hover retains the exact level. The separate True Colors plugin supplies provider hues; without it, badges are gray.

Declared minimum: BB 0.46.1 / SDK 0.6.49; tested on BB 0.47.1. Full-trust plugin using experimental APIs and the standard sidebar. Install `model-effort-badges` in BB. Stores no server data and adds no telemetry; BB and providers have their own data handling.
