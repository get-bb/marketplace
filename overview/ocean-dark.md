## What you get

Blue-grey backgrounds give the sidebar, conversation, and panels distinct surfaces. Sky-blue buttons, links, and focus rings share one accent, with teal highlights and readable text.

The code palette carries these colours into syntax highlighting, diffs, and file previews. A coordinated ANSI palette covers the integrated terminal.

## How it works

Install the plugin, then select Ocean Dark in Settings → Appearance. Installation adds a theme choice without selecting it. The theme preserves BB's layout and fonts.

Ocean Dark is a dark-only palette. It stays dark even when the client's appearance setting is Light or System. Select another theme to restore a palette that follows that setting.

## Requirements

Requires BB 0.47.1 or later and Plugin SDK 0.6.79 up to, but not including, 0.7. No account, API key, external font, or separate service is required.
