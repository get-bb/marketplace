## Your notes beside your work

Capture an idea without leaving the current screen. Pad keeps a Markdown outline in a panel on the right of bb, or a full-screen sheet on phones. Click to write, indent related notes, fold branches, and zoom into a topic. Search, move, and complete notes from the keyboard.

## A file you control

Notes stay in one local Markdown file on your bb server, with timestamps and a local Git history. Choose the storage folder in settings. You can edit the file in your own editor; Pad picks up those changes. It never pushes your note history.

Use `bb pad add`, `bb pad today`, and `bb pad search` from a terminal. When you ask an agent to save a note, it can use the `pad_add` tool.

## Review when you choose

Daily review is off by default. Select a project and enable it to open or resume an agent conversation about unresolved notes. The agent proposes task, knowledge, keep, or drop and waits for your approval. Knowledge needs your project's own destination and workflow. A note stays pending until you resolve it.

## Requirements

Requires bb 0.49.0 or later and Git on the bb server. Note capture needs no external account. Optional reviews send pending note text to the selected project's agent provider and use its normal quota or billing. Pad runs with the same full trust as other bb plugins.
