bb keeps one list of sidebar icons for every device, so hiding an icon on your phone hides it on your desktop too. Phone Rail is bb's own icon rail with one difference: phone-sized screens keep their own set of icons, in their own order. Wider windows keep bb's shared choice.

## What you get

- **On a desktop window**, bb's rail as you know it: the same icons, order, badges and menus, and bb's own Customize navigation editor.
- **On a phone**, the phone's own icons. Until you change anything, that is the same set as everywhere else.
- **Customize navigation on a phone** opens bb's customize list in a sheet: tick an icon to show it, drag to reorder it. Hide from rail on a phone hides the icon there only.
- **Same as wider windows** drops the phone's set and goes back to the shared one.
- **Customize phone navigation** in the desktop rail's More menu sets up the phone from the desktop.
- **Hidden icons stay reachable** in More. A plugin page installed after you set up the phone starts in More there.

## Set it up

Pick Phone Rail in Settings → Appearance → Navigation. With Navigation on Automatic, installing it picks it already. Set Navigation back to Rail, or disable the plugin, to return to bb's own.

## What counts as a phone

bb tells a navigation plugin whether it is using its compact (phone) layout: a window narrower than 768 pixels. That covers the iPhone app and a phone's browser, and also a desktop window made that narrow. bb does not say which device is asking, so every phone shares one set, saved on your bb server.

## Requirements

bb 0.48 or later. No account, service or API key.
