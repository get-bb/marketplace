Keep a project's threads together, from the first message through the archive. Use the status groups above the cards to jump to threads that need your attention or are still running.

## What you can do

- Collapse projects and individual branches in the thread tree. Pin frequently used projects to the top and pin threads among their siblings through BB's thread menu.
- Start a thread in a specific project with **+** or open **Архив** (Archive) to show its archived threads in the same tree.
- Scan thread counts for projects that need attention and use **Ждут вас** (Waiting for you) and **В работе** (In progress) to jump across projects.
- See usage percentages and available reset times below the thread list for providers that report limits through BB.

## Setup

Requires BB 0.50.1 or later. In **Settings → Appearance → Sidebar thread list**, choose **Карточки проектов** (Project Cards). Sidebar labels are in Russian. The optional limits panel uses providers configured on BB's primary host that report usage through BB.
