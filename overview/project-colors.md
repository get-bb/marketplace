Organize busy bb sidebars visually without renaming projects or changing how
threads are grouped.

## What you get

Project Colors adds a compact picker to every project heading in the bb
sidebar. Choose from seven focused options: red, orange, yellow, green, blue,
purple, or pink. The selected color gives the project a square translucent
header and softly tints every thread nested inside it.

Select the active color again to restore bb's default styling.

## How it works

The plugin uses bb's trusted content-script lifecycle and the host's stable
`data-sidebar-project-id` marker. It does not replace the sidebar or alter
projects, threads, or server data. Preferences stay in client-local storage.

## Requirements

Requires bb 0.42 or later. No external service, account, API key, or paid
subscription is needed.
