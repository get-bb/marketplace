## Organize work by folder

Create projects on connected devices and divide them into nested sections backed by real directories. Start section chats with BB's standard composer in the selected folder. Edit working rules in AGENTS.md and rename section labels from the management page.

## Keep history beside the work

Chat history snapshots and supporting files use a hidden .bb/chats directory. BB remains the canonical chat store; binary attachments stay in BB. These exports organize your work and do not replace a full BB backup.

## Archive and restore

Move a section, its nested folders and chats into a hidden archive inside the project. Restore the original paths, rules and chats later. Creating a section with a matching archived name offers restoration. Running chats prevent archiving, and restoration never overwrites an occupied folder.

## Requirements

Requires BB 0.43+ and connected macOS or Linux devices with local-path project sources. Live verification was performed on macOS. Windows paths are not supported. No additional account, API key or external service is needed.

The interface supports English, Russian, Spanish, French, German, Portuguese, Simplified Chinese, Japanese, Korean, Hindi and Arabic. English is the default; a language selector saves your choice in this browser. Arabic uses right-to-left layout. Some BB interfaces used by this plugin are experimental.
