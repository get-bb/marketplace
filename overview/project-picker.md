## What you get

- A centered picker on Cmd+N with a search field and your projects. "No
  project" comes first, then projects by their most recent thread activity.
- Type to filter by project name or path.
- Arrow keys and Enter, or Cmd+1 to Cmd+9, to pick. Esc or a click outside
  closes.
- Picking a project opens BB's new-thread screen for it with the prompt
  focused.

## Shortcut

While the plugin runs it owns Cmd+N and moves BB's own New thread command to
Cmd+Shift+O. If you already changed either binding, the plugin leaves your
bindings alone. Disabling or uninstalling the plugin removes the bindings it
wrote, so Cmd+N opens a new thread again.

The picker is also in the command palette as "Project Picker: new thread in
project…".

## Requirements

Runs inside BB with no account, service, or network access.
