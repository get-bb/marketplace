## Organize related repositories

Create named spaces from existing BB projects and reference folders. Choose a primary project and save shared instructions. A project can belong to several spaces; each thread has one placement.

## Work from the sidebar

Browse common space threads and project threads in one sidebar. Open a project's chat form beside its launch button. Move or copy threads through native menus. Questions and approvals stay yellow until answered; unread failures and completed work use red and green. Native Continue from retains the source thread's space and scope.

## Add shared context

Optionally connect ai-workspace to organize shared files, notes and groups. Its settings show CLI versions, folder registration and configuration state. Repowise adds code queries across the space's repositories, with indexes reused per checkout. Agents receive scoped read tools in new sessions.

## Requirements and boundaries

Requires BB 0.49 or later. The interface is currently in Russian. ai-workspace and Repowise are separate optional CLIs; the ai-workspace installer downloads verified release assets from GitHub. Fast Repowise preparation makes no model calls and requires no API key. Other folders provide context without expanding BB permissions. Each repository keeps its own Git state; a native worktree covers the selected project.
