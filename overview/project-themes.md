## Make each project feel familiar

Give each project a color that carries through its thread rows, browser tabs and
workspace background. Tints blend with your light or dark bb theme.

Choose from eight muted presets or use the color picker. Each project has one
shared color and three independent switches, so you can keep just the accents
you want. All three are on by default.

## Set it once

Open **Settings → Project Themes → Project colors**, select a project and choose
its color. Preview the result, then click **Save**. Your choices sync across bb
windows. **Reset** restores defaults for that project.

## Good to know

Requires **bb 0.45 or later**. No external accounts or services.

External browser tabs use a colored bb favicon. Internal Browser tabs are tinted
inside bb. In split views, the shared background follows the active route's
project. Thread colors apply to the standard bb thread list.
