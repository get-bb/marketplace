## Your review queue

Browse open pull requests you authored, requests for your review, and open work in your bb projects’ GitHub repositories. Filter by status, author, or reviewer, search the known registry, and pin work you want to revisit. Recent merged and closed pull requests are available through the status filter.

## Follow the work

See CI, review, and mergeability status beside each pull request. Open its Summary or read-only Changes, then return to a linked bb thread to continue. Stacks and labeled branch dependencies stay together, with merged prerequisites visible as context.

Paste a GitHub pull request URL to open or link it. Thread references in descriptions can associate accessible threads; verified origin markers also check the server and repository. You can manage links and choose a preferred thread.

## Requirements and privacy

Supports GitHub.com. Install and authenticate the GitHub CLI on each connected machine you want to use as a source. Each machine uses its own account and repository permissions; there is no fixed account.

Pull Requests reads GitHub and stores cached snapshots, thread associations, and preferences in bb. It does not submit reviews or merge pull requests. Source, freshness, offline machines, and incomplete discovery are shown so cached information is not mistaken for a current result. Open searches are limited to 1,000 results per query; merged and closed history is limited to the latest 100 authored pull requests per account.
