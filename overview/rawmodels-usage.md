See your RawModels subscription allowance beside Codex and Claude Code limits in BB's usage card: the rolling 5-hour window and the monthly output-token allowance, with reset times.

## Setup

Nothing to configure. The plugin reuses the login of the pi coding agent (`pi install npm:@rawmodels/pi`, then `/login rawmodels`). `RAWMODELS_API_KEY` in the machine's environment works too.

## Privacy

The key is read and used only on your machine. The BB server receives just the usage numbers.

## Limits

Covers the subscription token pool. Prepaid credit balance and credit-billed models are not shown.
