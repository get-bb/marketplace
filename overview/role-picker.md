## Choose a specialist while writing

Select a role beside the message composer and send normally. The role applies in the same conversation, without creating another chat. Choose no role to return to the general assistant. Your composer model and permission choices stay in effect.

## Requirements

Works on its own with six included specialists. Install Agent Roles optionally to select your custom profiles too. Role selections are stored in Role Picker metadata; imported roles remain distinct from built-in roles. This plugin uses a scoped content script around the BB message submission routes because SDK 0.4.87 has no submit middleware. Recheck compatibility after BB updates. Composer actions are hidden in compact mode.
