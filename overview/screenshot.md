Take a screenshot with the native macOS crosshair and attach it directly to your BB message.

Click the camera beside Send, select an area, and release. The PNG appears in the
current draft. No manual paste and no machine selector: capture runs only on the
Mac displaying BB, verified through an authenticated local connection.

Requires this Mac to be connected to BB, local network access for the viewing site,
and macOS screen recording permission. Escape cancels. Temporary files are deleted
after transfer, with a two-minute fallback expiry.
