## What you get

- Hold Cmd and tap backtick to step through your seven most recent sessions. Release Cmd to open the selected one; Escape cancels.
- Point at a card to select it, or use the arrow keys and Tab.
- Horizontal cards or a vertical list: choose in Settings → Installed plugins → Sessions’ switcher → Layout.
- Each session shows its project and BB’s own live sidebar status: running, unread, error and waiting for input.
- Provider icons follow the sidebar’s Organize → Rows → Provider icons setting.

## How it works

The list is ordered by the sessions you actually opened, so a working agent does not reshuffle it. Opened sessions come first, then recently updated ones. Archived, hidden and deleted threads are left out. The visit history stays in this BB profile’s local storage.

When a Browser tab is open, the switcher appears beside it, because the native page draws above plugin overlays.

## Shortcut

Cmd+backtick on Mac and Ctrl+backtick elsewhere by default. Rebind it in Settings → Keyboard. The command palette also opens the list for click or Enter selection.
