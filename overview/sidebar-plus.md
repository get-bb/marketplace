## Organize your projects

Sidebar Plus replaces BB's thread list with a project-first view. Pinned threads, pinned projects, all projects, and hidden projects have their own collapsible sections.

Pin the projects you use most, hide the ones you do not need in your current view, and reorder projects to match your workflow. Sidebar options let you choose grouping and project order and toggle project search. Project context menus also provide project settings, renaming, and removal.

## Manage threads from the sidebar

See thread status and pull request indicators alongside your thread list. Open a thread's context menu to inspect its project, branch, and pull request details without opening the conversation.

From the same menu, open a thread in a split, mark it read or unread, pin or unpin it, rename it, archive it, or delete it. Your sidebar preferences stay in sync across BB windows.

## Requirements and activation

Requires BB 0.45 or later and plugin SDK 0.6.15 or later.

BB activates a thread list plugin when it is installed. If another thread list is active, select Sidebar Plus under **Settings → Appearance → Sidebar**. To return to BB's default thread list, run `bb settings ui reset sidebar.threadListProvider`.

See the [plugin repository](https://github.com/juanem1/bb-sidebar-plus-plugin) for installation and development instructions.
