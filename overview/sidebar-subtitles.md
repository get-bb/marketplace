## A calmer sidebar

Add section headings above navigation destinations to group tools by the way you work. Use the inline editor with explicit Save, Cancel and Delete actions. Escape cancels a draft; leaving the field does not save it.

## Native destinations, your labels

Uses BB's supplied navigation items, activation and split gestures. Existing native subtitle preferences are preserved, as are item ordering and visibility. If another navigation provider is selected, choose Sidebar Subtitles in Settings → Appearance.

Only one navigation provider is active at once. Disabling the plugin restores the original navigation; saved headings remain. Names are limited to 120 characters and concurrent edits fail without overwriting another change.
