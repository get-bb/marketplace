Superhuman-like keyboard navigation for BB: see where each shortcut goes and
set up a new thread without the mouse. [Superhuman](https://superhuman.com/mail)
is the email client where every action has a key.

## Instant hints

Hold a modifier to show the remaining keys next to visible controls immediately.
The badges are small grey pills that follow your current bindings. On a Mac,
holding Command turns a Command+Shift+M hint into Shift+M; add Shift to see M.

## New thread setup

Set up a new thread before typing its prompt. While the prompt is empty, 1 opens
the project, 2 the model, 3 the machine and 4 the branch; numbers then choose
options in BB's native menus. In the model picker they choose the provider, and
BB restores its last model and reasoning. The first ten options are numbered
1–9 and 0; BB's own keys reach the rest. After each choice, focus returns to
the prompt. Typing hides the numbers; press Escape first to start a prompt with
a digit.

## Search and plugins

Outside text inputs and open menus, slash opens BB's existing Search threads.
The plugin leaves your command-palette binding and Cmd+F alone.

Command+P on a Mac and Ctrl+P elsewhere open the Plugins page. BB's Quick open
file has the same default key, and BB gives a plugin command no key that
another command uses, so clear or change Quick open file's key in Settings →
Keyboard first. The command is also in the command palette.

## Settings

Enable hints, slash search and numbered setup independently in plugin settings.
On phones and tablets, where touch is the main input, they stay off.

## More San Francisco Plugins

Super Hotkeys is one of the San Francisco Plugins, a family of BB plugins. The
others:

- **Bookmarks**: save any chat message and jump back to it from the thread's
  right panel.
- **Dia Sidebar**: the sidebar's navigation as a compact, wrapping grid of
  icons.
- **Pool Usage**: how much of each provider's capacity is in use and when it
  frees up, in the sidebar footer.
- **Server Switcher**: if you run several servers on bb connect, one click opens
  the next online one.

See all of them, with install steps, at
[github.com/rebryk/bb-plugins](https://github.com/rebryk/bb-plugins).
