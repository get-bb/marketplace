Paste into BB's terminal from a phone or tablet.

## Paste button

On a touch screen, BB's terminal offers no Paste, and pressing and holding it
does nothing. Terminal Paste puts **Paste**, a clipboard icon, in the header of
the right-panel pane that shows the terminal. Tap it to paste the clipboard
into that terminal. The text arrives the way a keyboard paste does, so a shell
with bracketed paste takes several lines without running them one by one. The
button shows on touch screens only.

## iPhone, iPad, and Android

On iPhone and iPad, iOS may show its own **Paste** next to the button; tap it
as well. Where the page can't read the clipboard, as in the BB app on Android
or on a plain `http://` address, **Paste** opens a text field instead. Paste
into the field with the system's menu, then tap the field's **Paste**.

## More San Francisco Plugins

Terminal Paste is one of the San Francisco Plugins, a family of BB plugins. The
others:

- **Super Hotkeys**: Superhuman-like keyboard navigation, with shortcut hints,
  slash search, and number keys that set up a new thread.
- **Bookmarks**: save any chat message and jump back to it from the thread's
  right panel.
- **Dia Sidebar**: the sidebar's navigation as a compact, wrapping grid of
  icons.
- **Pool Usage**: how much of each provider's capacity is in use and when it
  frees up, in the sidebar footer.
- **Server Switcher**: if you run several servers on bb connect, one click opens
  the next online one.

See all of them, with install steps, at
[github.com/rebryk/bb-plugins](https://github.com/rebryk/bb-plugins).
