## Make replies easier to scan

Codex-inspired styling gives Markdown headings visible hash marks and separates headings, links, and inline code with distinct colors. Claude Code-inspired styling uses neutral heading text, italic quotes, and lavender or blue inline code. Both styles follow BB’s light or dark mode and apply to earlier replies as well as new ones.

## Pick a style and font

Open **Settings → Plugins → Terminal Replies** to preview both styles. Choose the Claude Code style for Codex replies, or use BB’s default styling for either provider. Pick JetBrains Mono, BB’s terminal font, or BB’s chat font. The Claude Code style also lets you choose its inline code color.

## Requirements

Works in BB desktop and web chat on BB 0.50.1 or later. JetBrains Mono is optional and is loaded from your device when installed. The plugin uses BB’s existing thread metadata and applies the styling locally. It requires no extra account or external service.
