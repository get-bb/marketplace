## Thread cards

Hover a thread in the sidebar, or focus it with the keyboard, to see what it is doing without opening it: status, model and run time, the latest agent message, and the repository and pull request it works on. Your active thread stays where it is.

## Section cards

Hover a section header to see inside it without expanding it. The card shows where the work lives, whether anything needs you, such as open questions or failed runs, and how many threads are working or unread. When nothing needs action, the card says nothing about it rather than adding a reassurance line.

## Details

A card loads its summary after the pointer comes to rest on a row, so sweeping across the sidebar does not send a request for every row it crosses. Only one card is open at a time. The unread count follows bb's own rule, so it matches the sidebar.
