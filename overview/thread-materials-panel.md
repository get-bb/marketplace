## Files

Search by name or path and filter by extension. Group files by type and sort each group by name, date, or size. Turn grouping off for a single sorted list. Select a file to open it in BB's preview. Right-click a file or image and select **Go to message** to find its most recent mention.

## Images

Browse thumbnails from thread storage and supported local attachments. Click a thumbnail to view the image at full size.

## Links

Search the web links collected from visible user and assistant messages. Open a link in BB or select **Go to message** to jump back to its source. Select **Load earlier messages** to search earlier messages.

## Commands

Search and copy terminal commands suggested by the agent. Select **Go to message** to read the original instructions.

## Requirements

Requires BB 0.50.1 or later with Plugin SDK 0.6.157 or later. File dates and sizes depend on metadata from the thread's host.
