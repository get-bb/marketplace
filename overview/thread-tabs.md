Up to eight chat tabs inside each thread, sharing one workspace.

Use **+** for a fresh conversation with any installed model, the output’s **⋯ → Fork into new tab** to start a New chat draft with the conversation transcript attached, and **×** to close a tab. The history button restores closed tabs. Extra sessions stay out of the sidebar, and the original thread keeps its workspace, terminal, and files.

Right-click a tab to rename it, mark it unread, copy its transcript or link, or close other chat tabs. Main remains open with its thread.

The same output menu includes BB’s native **Fork into new thread**. The tab strip has no Fork button.
