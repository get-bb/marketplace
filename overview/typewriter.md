## A little mechanical feedback

Hear a short click as you type in BB, with distinct sounds for space, deletion and Enter. Adjust the volume or turn typing sounds off from the plugin settings. A preview button lets you check the sound before enabling it.

## Bring your own sound pack

Five IBM Selectric WAV sounds are included with the plugin, ready on a new install. Import a personal WAV set to get a different feel: key.wav plus optional key2.wav, space.wav, delete.wav and enter.wav. Files stay on the device where you import them and are not uploaded or synced. Import separately on each device and use recordings you have permission to use.

## Privacy and setup

The plugin does not store typed text and does not request microphone access or macOS Input Monitoring. Password fields and keyboard shortcuts stay silent. Sounds are enabled on a new install; disable any separate typing-sound helper to avoid duplicate clicks. Browser sound permissions, output volume and autoplay restrictions still apply.

No account, API key, subscription or external service is required. Imported WAV files are limited to 1 MB each and 4 MB per pack.
