## What you get

Unified Inbox lists Gmail, WhatsApp, Messages, and LinkedIn in one tab. You read a conversation, reply where that source can send, and start a new WhatsApp chat from a phone number. You can mute a conversation and it stays in the list. A PNG, JPEG, GIF, or WebP image in a mail message is shown in that message. Other files stay download chips.

Each source keeps one login. WhatsApp is one number. LinkedIn is one profile. Gmail is the mailbox you connect. Messages is the local account on this Mac.

## How to connect

Open BB Settings and choose Unified Inbox.

Gmail uses a Desktop OAuth client that you create in your own Google Cloud project. Paste the client id and the client secret on the settings page. Enable the Gmail API and the People API, and add your Google account as a test user. A client that stays in Testing expires after 7 days. Google can show an unverified-app warning on the first sign-in.

WhatsApp connects from a QR code on the settings page. The phone treats that link as a linked device, in the same way as WhatsApp Web. A phone code is available when a scan is not. Pairing spends one of the account's linked-device slots.

LinkedIn sign-in opens a Chrome window that belongs to this plugin. Sign in there. A shared post in an open chat shows the post's words and picture. The list still says "Shared a post". In an open chat, hover a message to react with a heart, a like, a dislike, or a laugh, or to reply to that message.

Messages reads the local Messages database through imsg. Install imsg on the Mac, and grant BB Full Disk Access. This plugin does not install imsg, and it does not grant that permission.

## Limits

The unread count in the Messages app stays in the Messages app. This inbox keeps its own unread mark.

A PDF and an SVG stay download chips. A file that is too large to show is saved in your Downloads folder.

People who change this plugin start from the file AGENTS.md.
