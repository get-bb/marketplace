## Will your quota last?

Open Usage before you start a long run. Read your remaining allowance, the time left in each window and the forecast at your current pace. Codex also reports the number of manual resets you have in reserve when that balance is available.

## See where the tokens went

Switch to Threads, choose five hours or seven days, and open the conversation behind a spike. The breakdown uses local session logs, including cache tokens. The provider reports subscription quota separately.

## Use your connected accounts

A single Codex or Claude Code account opens directly. When both report usage, a selector switches between them. Claude Code supplies quota windows through BB. Its connector does not expose a manual reset balance.

The separate GitHub Actions row tracks monthly compute for the author’s GitHub account in this release. Other users can use the provider and thread views independently.
