## What you can save

Use **Save thread to wiki** in a BB thread’s menu to archive the full conversation. Use **Save to wiki** on a message or selected text to keep a specific passage. The plugin saves Markdown files you can open in Obsidian or any Markdown editor. A reference to the original message is included when available.

## Sync across devices

Keep your Markdown folder in iCloud Drive or another cloud storage service to sync the same files across your devices.

## How notes stay up to date

A configured BB automation reads the queue of saved sources and can add findings and source links to your topic notes. Run the automation from the BB command palette or use its regular schedule.

## Requirements

The BB server needs Python 3 and access to the Markdown folder. Point wikisuppy at a folder with a `SCHEMA.md` file and configure a BB automation to process sources into topic notes. See the [wikisuppy setup guide](https://github.com/yknnv/wikisuppy#installation).
