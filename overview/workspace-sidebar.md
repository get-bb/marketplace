Ultra Sidebar replaces BB's thread list with collapsible sections by project or status, pinned threads on top, and subagents nested under the thread that spawned them.

## What you get

- **One place for parallel work.** Group by project or status, pin what matters to the top, and nest subagents under their parent thread.
- **Act in batches.** Multi-select, drag, reorder, snooze, and mark work done. Undo and redo organization changes.
- **Stay on the keyboard.** Move rows with Alt+↑/↓, go back and forward through opened threads with Mod+[ and Mod+], and use shortcuts and context menus without opening every thread.
- **Review in context.** See branches, change counts, pull requests, checks and agent activity from the sidebar, and the stack a branch belongs to when the PR Stacks plugin is installed.
- **Know the project at a glance.** Project headings and rows show each project's own icon or logo.

## Requirements

Open **Settings → Appearance → Sidebar** and select Ultra Sidebar. This plugin owns the sidebar thread list; only one replacement can be active.

Use `bb sidebar --help` to read and file threads from a terminal.
