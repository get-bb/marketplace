## What you get

Read spreadsheet cells in BB’s file panel, switch between sheets, and keep column letters and row numbers visible while you browse. The table displays merged cells and date values.

The Spreadsheets button in the thread header lists workbooks from the current workspace and thread files. Choose a workbook to open its preview.

## Limits

Each sheet displays up to 1,000 rows and 100 columns. A notice shows when the preview is truncated. If a workbook cannot be parsed, BB’s built-in preview is shown with an error message.

This is a read-only preview for `.xlsx` and `.xlsm` files. Legacy `.xls` files are not supported. Formulas are not recalculated and macros are not executed.

## Requirements

Requires BB 0.46 or later and Plugin SDK 0.6.49 or later. No external account or separate spreadsheet application is required.

If another viewer takes priority, select Spreadsheet table under Settings → Files → File openers for `.xlsx` and `.xlsm`.
